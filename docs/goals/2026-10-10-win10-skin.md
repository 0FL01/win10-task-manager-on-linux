Status: active

Last updated: 2026-10-10

## Objective
Единственный интерфейс Task Manager (egui) выглядит как диспетчер задач Windows 10 по референсам `references/` (вкладки Processes, Performance, Details, Services):
- геометрия и цвета не-текстовых элементов совпадают с измерениями;
- текст совпадает по положению с допуском ±1 px;
- реализация чистая: никаких ресурсов Microsoft;
- Adwaita-интерфейс удалён.

## Execution Directive
Выполнить замороженные Required Outcomes в рамках Change Envelope, подтверждая каждый через Primary Evidence. Брать наименьший нерешённый outcome. Не добавлять требования из ревью, тестов, инструментов, спекулятивных рисков или опционального текста источника. Цель закрыта, когда каждый outcome решён, а затронутые ограничения по-прежнему выполняются. Существенную работу остановить при доказанном внешнем блокере, на границе утверждённого бюджета или когда у оставшихся действий в рамках объёма нет фальсифицируемого ожидаемого результата; записать точное доказательство и минимальное условие разблокировки.

### Constraints
- C1: clean room — в коде, ассетах и тестах нет пикселей, иконок, шрифтов и кода Microsoft; иконки интерфейса рисуются свои; референсы не коммитятся. Исключение по решению пользователя: иконка приложения — предоставленная пользователем фанатская перерисовка.
- C2: приложение называется Task Manager везде (бинарник и пакет `taskmanager`, app id `io.github.taskmanager.TaskManager`, домен переводов `taskmanager`, настройки `~/.config/taskmanager`); бэкенд Mission Center (magpie) сохраняет свои имена; авторство Mission Center указано в README, About и заголовках файлов (решения пользователя 2026-10-10).
- C3: инварианты порта из AGENTS.md сохраняются: нет I/O в `ui`/`logic`, перерисовка только по событиям, ограниченные каналы.
- C4: производительность не хуже исходной (`perf/history/bench-latest.md`: UI CPU в простое ~0.75%, около 1 кадра на обновление; метод и границы сравнения — `perf/README.md`). Текущий `cargo xtask bench-idle` измеряет только egui wgpu/glow.
- C5: GPL-3.0-or-later; Selawik распространяется по OFL с файлом лицензии.
