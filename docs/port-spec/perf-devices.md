Global helpers used by every page below.

**Formatting (`src/main.rs`)**
- `to_human_readable_nice(value, &DataType)` (src/main.rs:387) → `to_human_readable_adv_str` (src/main.rs:303). Units table `["", "K","M","G","T","P","E","Z","Y"]`; divisor 1024 if base2 else 1000; if `use_bytes == false` value is multiplied by **8** and the suffix becomes `ps`/`` instead of `/s`/``. Exponent is forced to ≥ `min_exponent` before the magnitude loop, so bytes are never shown below K. Decimals: `2` if `|value| < 10`, `1` if `< 100`, else `0` — only when `exponent > min_exponent`, else `0`. Final format `"{value:.dec} {UNITS[exp]}{'i' if base2}{unit_label}{'/s'|'ps'|''}"`.
  - `DataType::Hertz` → label `"Hz"`, min_exponent 0, always base10, value as-is.
  - `DataType::Watts` → `"W"`, min_exponent −1. `Volts` → `"V"`. `WattHours` → `"Wh"`.
  - Bytes types: `MemoryBytes`, `DriveBytes`, `DriveBytesPerSecond`, `NetworkBytes`, `NetworkBytesPerSecond` read gsettings keys `performance-page-memory2-use-bytes` / `-use-base2`, `performance-page-drive-use-bytes` / `-use-base2`, `performance-page-network-use-bytes` / `-use-base2` (mapped in `data_type_setting_byte_setting` / `_base_setting`, src/main.rs:248-301; note the `memory2` key quirk). Drive/Network `*PerSecond` types pass `per_second = true`. `B`/`b` chosen by the bytes setting.
  - Defaults (gschema): memory bytes=true base2=true; drive bytes=true base2=true; network bytes=**false** base2=**false**.
- `to_short_human_readable_time(secs)` (src/main.rs:201): `"{mins} minutes {secs} seconds"` style; minutes only if `mins>0`, seconds appended only if `secs != 0`. Plural via `ni18n_f("{} second","{} seconds", …)` / `"{} minute"/"{} minutes"`.
- `to_long_human_readable_time(secs)` (src/main.rs:98, gdu port): year = `60*60*6*1461`, month = `60*30*1461`, day/hour/minute = 86400/3600/60. Concatenation rules: `years>0` → `"{}, {} and {}"` (y,m,d) if days≠0, `"{} and {}"` (y,m) if months≠0 else years; `months>0` → `"{} and {}"` (m,d) if days≠0 else months; `days>0` → `"{} and {}"` (d,h) if hours≠0 else days; `hours>0` → `"{} and {}"` (h,m) if minutes≠0 else hours; `minutes>0` → minutes; `seconds==0` → `"{} seconds"`; else `"Less than a minute"`.
- `MK_TO_0_C = -273150` (src/performance_page/mod.rs:82) — millikelvin → °C is `(mk + MK_TO_0_C) as f32 / 1000.0`.

### 4.4 Availability detection and per-graph configuration (`configure_actions_graph`, gpu.rs:286-498)
- Support flags: `enc_dec = encoder_percent.is_some() || decoder_percent.is_some()`; `memory = total_memory || used_memory || total_shared_memory || used_shared_memory` present; `power = power_draw_watts.is_some()`; `clocks = clock_speed_mhz || memory_speed_mhz` present; `temp = temperature_c.is_some()`.
- `graph_support: u8` bitfield, bit `i` for `[true, enc_dec, memory, power, clocks, temp]` (bit 0 always true = "disabled" slot) (gpu.rs:301-309).
- Saved setting values are validated against the bitfield: if `!graph_support.bit(saved)` → treat as `GRAPH_NONE` (gpu.rs:311-319 and again in the change handlers 329-332/349-352). Setting keys: `performance-page-gpu-graph-middle` (default **1** = encode/decode) and `performance-page-gpu-graph-bottom` (default **2** = memory), range 0..5, gschema:271-282.
- Per-capability extras:
  - `enc_dec`: enables the two Enc/Dec actions; if `encode_decode_shared` → set `encode_decode_shared` flag and set dataset 0 in both graphs to `FillToBottom` + `dashed=false`.
  - `memory`: enables memory actions; `set_dataset_max_scale(2, total_memory)` and `(3, total_shared_memory)` on both graphs; `gtt_available = total_shared_memory.is_some()`.
  - `power`: enables power actions; `set_dataset_max_scale(4, max_power_draw_watts)`.
  - `clocks`: enables clock actions; `set_dataset_max_scale(5, max_clock_speed_mhz * 1e6)`, `set_dataset_max_scale(6, max_memory_speed_mhz * 1e6)`.
  - `temp`: enables temperature actions.
- Actions are stateful `gio::SimpleAction`s in the `graph` group; `gpu_middle_none`/`gpu_bottom_none` enabled by default, all others disabled until the corresponding capability exists. Activating one writes the int to `performance-page-gpu-graph-middle` / `-bottom` (`set_middle_graph_settings` gpu.rs:1043-1052, `set_bottom_graph_settings` 1054-1063).
- Mutual exclusion (`set_middle_graph_states` / `set_bottom_graph_states`, gpu.rs:992-1041): selecting a non-None type on one graph **disables** that same type's action on the other graph; `None` never disables.

## 7. Cross-page notes for the port

1. **Message-id set** for these pages is exactly the `_()` strings in the blp files plus the `i18n(...)`/`i18n_f(...)`/`ni18n(...)` strings listed above. No `pi18n*` (context) calls exist anywhere in `src/performance_page/` — verified by grep, so there are no context-bearing msgids to preserve from these pages.
2. Non-translated user-visible strings that must **not** be turned into msgids: `"GPU {}"`/`"GPU"` in `gpu.rs:536-538`, `"Battery {index}"` fragment in `battery.rs:408-411`, `"{} {}"` vendor/model join, `ConnectionKind::as_str_name()` and `ConnectionState::as_str_name()` values, SMART `TestResult` Debug names, `"PCIe Gen {} x{} "`, `"S"`/`"R"`, `" / "` separators, `"{}%"`/`"{} RPM"`/`"{} °C"` numeric formats that use `format!` rather than `i18n_f` (e.g. `disk.rs:363,376`, `gpu.rs:721,963`, `fan.rs:223,249,270`, `battery.rs:408-419,513,526`).
3. Unit selection is **global state** (cached settings dict in `src/main.rs:361`); `DataType` →
   - disk: `DriveBytesPerSecond` (speeds), `DriveBytes` (totals, smart total read/written), `MemoryBytes` (capacity/formatted).
   - network: `NetworkBytesPerSecond` (rates/max bitrate), `NetworkBytes` (totals), `Hertz` (frequency MHz×1e6).
   - GPU: `MemoryBytes` (VRAM/GTT/total), `Hertz` (clocks MHz×1e6), `Watts` (power).
   - fan: no `DataType` (raw numbers/`{}` formatting).
   - battery: `WattHours` (energy/1000), `Volts`, `Watts`.
4. Each page's `graph_max_duration` label is a single shared label per page (disk/fan/battery) or bound via `bind … .label` (network/gpu); it is updated only on `performance-page-data-points` / `app-update-interval-u64` changes.
